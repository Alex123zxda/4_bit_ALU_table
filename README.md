# 4_bit_ALU_table
Программа на Python для вывода таблицы истинности 4-битного арифметико-логического устройства

Я специально не стал использовать bin(), потому что мне было интересно самому всё реализовать практически без использования встроенных функций. Это простая реализация последовательного 4-битного ALU в виде кода и последующий вывод таблицы истинности со всеми возможными его значениями.
